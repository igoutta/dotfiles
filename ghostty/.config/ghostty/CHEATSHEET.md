# ghostty: teclas

Prefijo `Ctrl-Espacio`, soltar, y luego una letra. Definidas en `config.ghostty`; lo cargado
de verdad: `ghostty +list-keybinds`. Mostrar esto: `keys ghostty`.

| Tecla | Acción |
| --- | --- |
| `Ctrl-Espacio` `v` / `s` | Nuevo split vertical (lado a lado) / horizontal (arriba y abajo) |
| `Ctrl-Espacio` `h` `j` `k` `l` | Ir al split de la izquierda / abajo / arriba / derecha |
| `Ctrl-Espacio` `z` | Zoom al split actual; otra vez para volver |
| `Ctrl-Espacio` `e` | Igualar tamaños de los splits |
| `Ctrl-Espacio` `x` | Cerrar el split (pide confirmación) |
| `Ctrl-Espacio` `t` / `n` / `p` | Pestaña nueva / siguiente / anterior (también `Alt-1`…`9`) |
| `Ctrl-Espacio` `r` | Recargar la config de ghostty |
| `Alt-Shift-←↑↓→` | Redimensionar el split |
| `Ctrl-Shift-C` / `Ctrl-Shift-V` | Copiar / pegar (seleccionar ya copia al portapapeles) |
| `Ctrl-Shift-F` | Buscar en la pantalla |
| `Ctrl-Shift-PgUp` / `PgDn` | Saltar al prompt anterior / siguiente |
